# Opencode with a local model: beginner practice

[German guide](DE/START.md) · [English companion](EN/START.md) · [Official sources](QUELLEN.md)

Read two own synthetic inputs, produce a file and validate integer arithmetic, ordering and exact source IDs. The preparation helper and checker run without models. New client installation and agent inference are not claimed. Preserved own 2026-09-19 outputs are explicitly an archive, not a fresh benchmark.

Downloads: [DE](downloads/OPENCODE-LERNPAKET-DE.zip) · [EN](downloads/OPENCODE-LERNPAKET-EN.zip). Existing servers and private configurations are not bundled. A new video is still in production.
